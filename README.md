# Immersive Dinner

An immersive dining experience for two. A digital theatrical interface acting as a score for a live dining experience.

## ✨ Features

- **3 Curated Scenarios**:
  - *First Date* (Первое свидание) — Playful icebreakers and engaging conversations
  - *Best Friends* (Лучшие друзья) — Deep and humorous moments for close friends
  - *Relationship Reboost* (Обновление чувств) — Rekindle warmth, intimacy, and shared memories
- **Multi-language Support**: English (`EN`), Spanish (`ES`), and Russian (`RU`)
- **Atmospheric Dark/Light Themes**: Minimalist typography with responsive theme switching
- **Integrated Dish Visuals**: High-resolution dish photography tailored to each dramatic act
- **Intuitive Touch Controls**:
  - Horizontal swipe navigation (swipe left/right to move between acts and scenes)
  - Swipe up to advance when the act timer completes
- **Host / Kitchen Mode**: Real-time synchronized control panel with live timer tracking, guest device pairing, and next-course prep notes

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/immersive-dinner.git

# Navigate into project directory
cd immersive-dinner

# Install dependencies
npm install
```

### Development

```bash
# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port shown in your terminal) to view the application.

### Production Build

```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run preview
```

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Custom atmospheric themes
- **Animations**: Motion (`motion/react`)
- **Icons**: Lucide React
